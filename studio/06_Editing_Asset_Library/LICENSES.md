# 06 — Editing Asset Library: licence register

**Rule:** a free download isn't automatically free for commercial use. Every asset in this library must have a row here before it's used in a client or brand video.

## Folder layout
```
06_Editing_Asset_Library/
  Overlays/        film grain, light leaks, bokeh (screen/add blend)
  Fonts_list.md    recommended Adobe Fonts (activate in Creative Cloud app)
  Sounds/          SFX and ambience (add only licensed files)
  Music/           only owner-supplied or licensed tracks
  Color/           LUTs and Lumetri looks
```

## Verified free sources to add from (check the licence at download time)
| Source | What | Commercial use | Attribution | Watch out |
|---|---|---|---|---|
| **Adobe Fonts** (included in your plan) | Fonts | Yes, for video and social | No | Activate inside the Creative Cloud app |
| **Adobe Stock "Free" collection** (inside AE 27 › Adobe Stock panel) | Video, images, audio, templates | Yes, under the Adobe Stock licence | No | Only items marked *Free*. Others cost credits. |
| **Instagram Edits app music and sound library** | Music and SFX | Licensed for use **on Instagram/Facebook** | No | Don't re-use that audio on YouTube |
| **YouTube Audio Library** (studio.youtube.com) | Music and SFX | Yes. Some tracks require attribution. | Sometimes | Check each track's licence type |
| **Pixabay** (pixabay.com) | Video, music, SFX | Yes (Pixabay Content License) | No | Don't redistribute as-is. No trademarked content. |
| **Pexels / Mixkit** | Stock video, music, SFX | Yes (their free licences) | No | Mixkit music has a separate licence. Read it. |
| **Mister Horse free tier** | Transitions and text presets for AE/Premiere | Yes (vendor FAQ) | No | Needs a free account |
| **Google Fonts** | Fonts (Cormorant, Playfair Display, Cinzel, Montserrat) | Yes (OFL) | No | Install via Font Book |

## How to log a new asset
Add a row with:
- file name
- exact source URL
- licence name
- download date
- attribution text (if any)

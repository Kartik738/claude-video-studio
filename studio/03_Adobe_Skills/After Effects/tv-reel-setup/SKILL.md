name: tv-reel-setup
description: Set up a vertical 9:16 social reel composition with safe-zone guide, organised folders and a grade layer. Use when asked to start a reel, short, or vertical video.
---
When asked to set up a reel:
- Create a 1080x1920 composition at the footage frame rate (default 30 fps), square pixels.
- Put items in folders: 01 Comps, 02 Precomps, 03 Footage, 04 Audio, 05 Images & Graphics, 06 Solids.
- Add footage in the given order, scaled to fill the frame (cover), without stretching.
- Add a guide layer named "SAFE ZONE (guide - not rendered)" showing the safe area: 14% from top, 20% from bottom, 12% from right, 6% from left.
- Add an empty adjustment layer named "Grade" above the footage.
- Never delete or replace existing items. Never close the current project without asking.
